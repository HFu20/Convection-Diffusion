# Convection-Diffusion
This is the Matlab code for the paper "Strang splitting structure-preserving high-order compact difference schemes for nonlinear convection diffusion equations" published in Communications in Nonlinear Science and Numerical Simulation, by Baolin Kuang, Shusen Xie and Hongfei Fu.  
Some structure-preserving high-order and efficient compact difference schemes for nonlinear convection diffusion equations by using the Lagrange multiplier approach and the operator splitting method.
